1. Главный принцип — абсолютная автономность (Offline First)

Приложение TimeFlow AI работает на 100% офлайн. В манифесте приложения полностью отсутствует разрешение INTERNET. Приложение не передаёт личные данные на внешние серверы и не использует сторонние аналитические SDK.

2. Запрашиваемые системные разрешения

2.1. Доступ к микрофону (RECORD_AUDIO): Используется строго для локального голосового ввода. Аудиоданные обрабатываются потоковой нейросетью внутри устройства и не сохраняются в файлы.

2.2. Фоновая геолокация (ACCESS_FINE_LOCATION, ACCESS_BACKGROUND_LOCATION): Используется строго для функции «Гео-трекинг» (авто-запуск задач при входе в геозоны). Координаты обрабатываются локально и не передаются в сеть.

2.3. История использования приложений (PACKAGE_USAGE_STATS): Используется для функции «Автотрекинг» для паузы таймеров при открытии игр и соцсетей.

2.4. Файловая система (Документы): Создание зашифрованных локальных бэкапов базы данных (AES-256) в папку Documents/TimeFlow AI.

2.5. Уведомления (POST_NOTIFICATIONS): Отображение текущего секундомера в шторке через защищённый Foreground Service.
